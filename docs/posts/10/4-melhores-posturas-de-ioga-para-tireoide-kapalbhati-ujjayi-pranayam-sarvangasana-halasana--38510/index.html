4 melhores posturas de ioga para tireóide - Kapalbhati, Ujjayi Pranayam, Sarvangasana, Halasana

Ioga

Iogatem muitas formas diferentes e é praticado para tratar diversos problemas que um indivíduo enfrenta. Existem diferentes tipos de posturas de ioga que ajudam muito no tratamento de certas doenças. Yoga ajuda muito no controlediabetes, problemas de tireóide, problemas nas costas, etc.

Ioga para Tireóide: 4 Melhores Poses / Asanas

A seguir estão algumas posturas de ioga usadas para ajudar com problemas de tireoide:

  1. Yoga Asana Kapalbhati Pranayam para problemas de tireóide

    É uma variação bastante eficaz do pranayama. Para isso, é preciso sentar-se confortavelmente no chão e com as pernas cruzadas. Agora, é preciso respirar profundamente e expirar imediatamente emitindo um som. Deve-se lembrar sempre, ao fazer este exercício, que é preciso expirar com força e rapidez, mas, por outro lado, é preciso inspirar gradual mas profundamente. Faça isso cerca de 10 vezes.

  2. Yoga Asana Ujjayi Pranayam para problemas de tireóide

    Para fazer este exercício, sente-se confortavelmente no chão e com as pernas cruzadas. Faça uma inspiração profunda lentamente usando ambas as narinas. Tente fazer um barulho de “assobio” enquanto inspira. Feito isso, aumente o tempo de inspiração e expire o máximo possível, sem pressurizar nenhuma outra parte do corpo. Este tipo de pranayama demonstrou ser extremamente eficaz em pessoas que sofrem de problemas de tireoide. Ao fazer este exercício, deve-se lembrar que deve haver um leve ruído sibilante ao inspirar. Quando isso é feito, a garganta fica contraída. Agora, preencha os pulmões com ar. Depois de fazer isso, tente fazer a postura Chin-Lock. Essa postura é feita tocando a garganta. Então, ao expirar, feche a narina direita e expire pela narina esquerda e faça isso pelo menos 10 vezes. Se uma pessoa tem alguns problemas cardíacos, não se deve prender a respiração, mas inspirar e expirar instantaneamente.

  3. Yoga Sarvangasana ou postura de suporte de ombro para problemas de tireoide

    Também é conhecido como “suportes de ombro”. Neste exercício, primeiro é necessário deitar-se sobre uma esteira e descansar no chão. Em seguida, tente levantar as pernas. Pode-se usar o apoio das mãos para fazer isso. Experimente apoiar as mãos nas costas para ajudar a permanecer firme nesta posição. Quando as pernas estiverem levantadas, tente deixá-las o mais retas possível, alinhadas com o corpo. Mantenha esta posição por cerca de meio minuto e depois solte.

  4. Yoga Halasana para problemas de tireóide

    Ao fazer a postura Sarvangasana descrita acima, agora traga as pernas para baixo, acima da cabeça. Apoie as mãos nas costas para apoiar esta posição. Permaneça assim por cerca de meio minuto; respire 10 vezes e depois solte.
