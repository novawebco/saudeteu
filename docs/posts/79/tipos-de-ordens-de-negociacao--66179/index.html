Tipos de ordens de negociação

Investindo

Todas as negociações consistem em pelo menos duas ordens para fazer uma negociação completa: uma pessoa faz uma ordem para comprar um título, enquanto outra coloca uma ordem para vender esse mesmo título. Os tipos de pedidos são os mesmos, seja para negociação de ações, moedas ou futuros.

Os traders têm acesso a muitos tipos diferentes de ordens que podem utilizar em diversas combinações para fazer negociações. Os principais tipos de ordens são explicados abaixo, juntamente com algumas formas comuns pelas quais podem ser usadas na negociação.

Principais conclusões

  • As ordens de mercado são executadas mais rapidamente, mas não garantem preços de execução específicos.
  • As ordens limitadas garantem preços específicos para as ordens, mas não serão executadas se os preços não atingirem o limite inicial.
  • As ordens stop, também conhecidas como “stop-loss”, tentam mitigar as perdas acionando uma ordem de mercado se a sua posição se mover muito contra você.
  • Esses três tipos básicos de ordens podem ser combinados para criar ordens mais complexas, como stop-limit e market-if-touched.

Os princípios básicos para fazer pedidos

Uma única ordem é uma ordem de compra ou uma ordem de venda e deverá ser especificada independentemente do tipo de ordem que está sendo colocada. Cada tipo de ordem detalhado abaixo pode ser usado para comprar e vender títulos. Tanto as ordens de compra quanto as ordens de venda podem ser usadas para entrar ou sair de uma negociação. Se uma negociação for iniciada com uma ordem de compra, ela será encerrada com uma ordem de venda. Se uma negociação for iniciada com uma ordem de venda, a posição será encerrada com uma ordem de compra.

Por exemplo, a negociação mais simples ocorre quando um trader espera que o preço das ações suba. Esse trader coloca uma ordem de compra para entrar na negociação e uma ordem de venda para sair da negociação. Esperançosamente, o preço das ações aumentou no período entre essas duas ordens, para que o trader obtenha lucro quando vender.

Alternativamente, se um trader espera que o preço das ações caia, ele colocaria uma ordem de venda para entrar na negociação e uma ordem de compra para sair da negociação. Isso é mais comumente conhecido como "venda a descoberto" ou "venda a descoberto de uma ação" - a ação é vendida primeiro e depois recomprada.

Ordens de Mercado (MKT)

As ordens de mercado compram ou vendem ao preço atual, qualquer que seja esse preço.Num mercado ativo, as ordens de mercado serão executadas imediatamente, mas não necessariamente ao preço exato pretendido pelo trader.

Por exemplo, um trader pode colocar uma ordem de mercado para comprar uma ação quando o melhor preço for US$ 129, mas a ordem pode ser para uma ação popular que vê milhões de ações mudarem de mãos todos os dias. Nos segundos entre o momento em que uma ordem é colocada e a hora em que é executada, o preço pode aumentar para US$ 129,50. O trader que colocasse uma ordem de mercado pagaria então mais pelas ações. Quando o preço se move em uma direção desfavorável após a colocação de uma ordem de mercado, isso é chamado de “slippage”.

As ordens de mercado são usadas quando você deseja que sua ordem seja processada o mais rápido possível e está disposto a arriscar obter um preço ligeiramente diferente do seu ideal. Se você estiver comprando, sua ordem de mercado será preenchida pelo preço “ask”, pois esse é o preço pelo qual outra pessoa está disposta a vender. Se você estiver vendendo, sua ordem de mercado será preenchida pelo preço de “oferta”, pois é o preço que outra pessoa está disposta a pagar no momento.

Ordens Limitadas (LMT)

Ordens limitadas são ordens para comprar ou vender um ativo a um preço específico ou melhor.Eles podem ou não ser preenchidos, dependendo de como o mercado está se movendo e de onde o trader define o preço limite. No entanto, se forem preenchidos, será sempre ao preço que o trader espera (ou a um preço melhor do que o esperado). Ordens limitadas são usadas quando você deseja ter certeza de obter um preço adequado e está disposto a arriscar que a ordem não seja atendida.

"Melhor" depende se a ordem é de compra ou venda. Por exemplo, se um trader colocar uma ordem de compra com limite com um preço de US$ 50,50, a ordem só será atendida se a ação puder ser comprada por US$ 50,50 ou menos. Se sua corretora não conseguir encontrar alguém disposto a vender essas ações para você por US$ 50,50 ou menos, a ordem não será executada.

Por outro lado, se você quisesse vender uma ação por US$ 50,50 ou mais, colocaria uma ordem de venda com limite e definiria o preço em US$ 50,50. A ordem só seria executada se outra pessoa estivesse disposta a comprar suas ações por pelo menos US$ 50,50.

Ordens de Parada (STP)

As ordens stop são semelhantes às ordens de mercado; são ordens de compra ou venda de um ativo ao melhor preço disponível. No entanto, estas ordens só são processadas se o mercado atingir um preço específico.Esse preço é definido na direção oposta que o trader espera que a ação vá, então esse tipo de ordem é usado como forma de limitar as perdas. É por isso que você frequentemente os ouvirá chamados de ordens de “stop-loss”.

Observação

Para uma ordem de compra, o preço stop deve estar acima do preço atual. Para uma ordem de venda, o preço stop deve estar abaixo do preço atual.

Por exemplo, se você possui uma ação que vale atualmente US$ 12,57, você pode colocar uma ordem stop para vender a um preço de US$ 12,50. Se o preço das ações cair para US$ 12,50 ou menos, sua ordem stop se tornará uma ordem de mercado para venda e você venderá automaticamente as ações pelo melhor preço disponível naquele momento. Se o preço não cair para US$ 12,50, nada acontece.

Os traders iniciantes só podem colocar ordens stop para vender, mas uma vez que os traders começam a vender ações, é quando as ordens stop para comprar se tornam úteis. Os traders que vendem uma ação querem que o preço caia, mas para se protegerem de um aumento repentino no preço, podem definir uma ordem stop para vender um pouco acima do preço em que venderam a ação.

Lembre-se de que vender uma ação a descoberto significa vendê-la primeiro e depois comprá-la para fechar uma posição (esperançosamente, depois que o preço cair). Um trader que vende uma ação a US$ 50,75 pode colocar uma ordem stop para comprar a US$ 60. Dessa forma, eles sairão automaticamente de uma negociação ruim assim que perderem US$ 0,25 por ação.

Ordens Stop-Limit (STPLMT)

Os traders normalmente combinam uma ordem stop e uma ordem limite para ajustar o preço que obtêm. As ordens stop-limit funcionam da mesma forma que as ordens stop, exceto que se tornam automaticamente ordens limite quando os preços-alvo são atingidos, em vez de ordens de mercado.

Tal como uma ordem com limite padrão, as ordens stop-limit garantem um preço específico para um trader, mas não garantem que a ordem seja executada.

Ao usar uma ordem stop-limit, os preços stop e limite da ordem podem ser diferentes. Por exemplo, um trader que coloca uma ordem de venda com limite de parada pode definir o preço de parada em US$ 50 e o preço limite em US$ 49,50. Nesse cenário, a ordem de venda com limite de parada se tornaria automaticamente uma ordem com limite quando a ação caísse para US$ 50, mas as ações do trader não seriam vendidas a menos que conseguissem garantir um preço de US$ 49,50 ou melhor.

Ordens de Trailing Stop

Tanto as ordens stop como as ordens stop-limit podem ser definidas a um preço específico ou podem ser definidas em relação ao preço de mercado. Quando uma ordem stop ou stop-limit flutua com o preço de mercado, essa é uma ordem trailing stop (ou ordem trailing stop-limit).Os comerciantes usam essa estratégia para proteger seus lucros.

Por exemplo, um trader pode comprar uma ação por US$ 50. Uma semana depois, o preço das ações pode subir para US$ 53. Esse trader pode definir uma ordem de trailing stop para vender $ 2 abaixo do preço de mercado. Se o preço das ações caísse para US$ 51 no dia seguinte, a ordem de trailing stop se tornaria uma ordem de mercado para venda, garantindo algum lucro para o trader. No entanto, se o preço das ações aumentasse para US$ 55 no dia seguinte, o gatilho da ordem de trailing stop aumentaria para US$ 53.

O preço de gatilho para ordens de trailing stop pode ser determinado pelo valor em dólares ou porcentagem, mas sempre será relativo ao preço de mercado.

Pedidos de mercado se tocados (MIT)

As ordens de mercado se tocadas (MIT) são semelhantes às ordens limitadas, exceto que não garantem um preço. Isso os ajuda a executar mais rapidamente, ao mesmo tempo que permite que os investidores estabeleçam preços-alvo em vez de comprarem ao preço de mercado atual. O trader define um preço e, se esse preço for atingido, a ordem do MIT se tornará uma ordem de mercado.

Por exemplo, suponha que um trader queira comprar uma ação que está sendo negociada atualmente a US$ 70, mas não quer pagar tanto. Eles podem colocar uma ordem de compra do MIT com um preço-alvo de US$ 60. Se o preço das ações cair para US$ 60, a ordem do MIT se tornará uma ordem de mercado e o trader comprará as ações.

Observação

Tal como acontece com uma ordem de mercado padrão, existe o risco de derrapagem nas ordens do MIT. As ordens do MIT apenas dão aos traders a capacidade de controlar o preço pelo qual uma ordem de mercado é acionada.

Pedidos com limite se tocados (LIT)

Uma ordem com limite se tocada (LIT) é como uma ordem do MIT, mas envia uma ordem com limite em vez de uma ordem de mercado.As ordens LIT são diferentes das ordens com limite padrão porque o trader pode definir tanto o preço de gatilho quanto o preço limite.

Por exemplo, suponha que uma ação esteja sendo negociada a US$ 16,50. Um gatilho de ordem de compra LIT poderia ser colocado em US$ 16,40 e um preço limite poderia ser definido em US$ 16,35. Se o preço subir para US$ 16,40 ou menos (o preço de gatilho), uma ordem com limite será colocada em US$ 16,35. Por se tratar de uma ordem com limite, as ações só serão compradas por US$ 16,35 ou menos. Se não houver ninguém disposto a vender suas ações por US$ 16,35 ou menos, sua ordem de compra não será executada, mesmo que o preço de gatilho do LIT tenha sido atingido.

O resultado final

Uma ordem de mercado é usada para entrar ou sair rapidamente de uma posição. Esta é a maneira mais rápida de atender um pedido, mas oferece menos controle sobre o preço. Uma ordem com limite, por outro lado, garante preços mínimos de venda e preços máximos de compra, mas não será executada tão rapidamente.

As ordens stop são usadas para limitar suas perdas com uma ordem de mercado quando uma negociação se volta contra você. As ordens stop-limit empregam as mesmas táticas, mas usam ordens limitadas em vez de ordens de mercado. As ordens de stop móvel e as ordens de limite móvel usam a mesma estratégia para proteger os lucros.

Ordens de mercado se tocadas acionam ordens de mercado se um determinado preço for tocado. Ordens com limite se tocadas enviam ordens com limite se um preço de gatilho específico for atingido.

Perguntas frequentes (FAQ)

Como escolho qual tipo de pedido usar?

Os traders experientes usarão muitos, senão todos, os tipos de ordens discutidos aqui. Saber quando usar cada um depende da sua estratégia de negociação e do tipo de posição. Por exemplo, se uma ação que você possui está caindo rapidamente e seu único objetivo é sair da posição o mais rápido possível, provavelmente você usará uma ordem de mercado. Se você mantém uma ação no longo prazo, mas deseja se proteger contra a queda da ação, convém usar uma ordem de stop loss. Se você tiver uma meta de lucro específica em mente, poderá usar uma ordem com limite para obter lucro automaticamente a esse preço.

Por que as bolsas de valores criam tantos tipos de pedidos?

As corretoras, e não as bolsas de valores, criam e controlam os tipos de ordens. Essencialmente, as corretoras oferecem todos esses tipos de pedidos para melhor atender o cliente. Mais tipos de pedidos oferecem mais opções sobre como negociar títulos. Se você é um novo trader e procura uma corretora, e duas corretoras são iguais em todos os aspectos, exceto que uma oferece mais tipos de pedidos, você provavelmente escolherá aquela que oferece mais opções.
