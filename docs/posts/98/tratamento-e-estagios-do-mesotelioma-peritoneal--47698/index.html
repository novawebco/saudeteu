Tratamento e estágios do mesotelioma peritoneal

Câncer

Nesta seção do artigo você aprenderá sobre os tratamentos para o mesotelioma peritoneal, estágios envolvidos no mesotelioma peritoneal.

Tratamentos para mesotelioma peritoneal

Existem vários tratamentos para o mesotelioma peritoneal. O prognóstico tanto dos pacientes com mesotelioma peritoneal quanto dos pacientes com mesotelioma não é tão bom. Os fatores abaixo influenciam a seleção do tratamento para o mesotelioma peritoneal. Estes são:

  • Em que estágio se encontra o seu câncer (mesotelioma peritoneal).
  • Outras condições médicas que você possui além do mesotelioma peritoneal.
  • Sua saúde e bem-estar geral.

Para remover o máximo possível do tumor da cavidade estomacal, algumas pessoas com dores abdominais localizadas recorrem à cirurgia no tratamento do mesotelioma peritoneal.

Para aqueles pacientes cuja condição de mesotelioma peritoneal está avançada, recomenda-se que sejam submetidos a uma cirurgia conhecida como citorredução – esse tipo de operação garante que o máximo de tumor possível seja removido. Para o mesotelioma peritoneal avançado, você tem a opção de optar porquimioterapiasozinho ou antes ou depois da cirurgia para mesotelioma peritoneal.

A triste verdade é que para o mesotelioma peritoneal,quimioterapiae a radioterapia não são as melhores opções porque foi comprovado que não funcionam bem. À medida que os médicos se esforçam para melhorar o tratamento, você poderá receber tratamento como parte do ensaio clínico. No futuro, estes ensaios gratuitos acabarão por melhorar o tratamento. Estamos, portanto, familiarizados com a participação em ensaios clínicos.

Cirurgia para tratamento do mesotelioma peritoneal

Ao contrário do mesotelioma pericárdico, a cirurgia é uma opção viável para o mesotelioma peritoneal. Para que um paciente que sofre de mesotelioma peritoneal possa participar nesta grande operação, é crucial que esteja bem. Para quem se qualifica para esta cirurgia o que acontece no processo é que o revestimento do abdômen também conhecido como peritônio é retirado, operação conhecida como peritonectomia. A principal razão para este processo é diminuir os sintomas do mesotelioma pericárdico.

Há também outro procedimento identificado como operação citorredutora para mesotelioma peritoneal. O objetivo desta cirurgia para o mesotelioma pericárdico é eliminar o máximo possível de câncer. Enquanto este processo está em curso, e ainda mais tarde,quimioterapiaé administrado diretamente na cavidade peritoneal para pacientes com mesotelioma peritoneal. Este processo para o mesotelioma pericárdico foi comprovado pelos médicos e resultados promissores foram testemunhados.

Quimioterapia para tratamento do mesotelioma peritoneal

A quimioterapia é uma boa opção para o mesotelioma pericárdico, mas não para o mesotelioma pericárdico. Medicamentos anticâncer são injetados nas veias de pacientes com mesotelioma peritoneal. Este medicamento pode ser administrado semanalmente dependendo dos medicamentos quimioterápicos. Este tratamento ambulatorial tem como objetivo diminuir e manter o mesotelioma peritoneal sob controle pelo maior tempo possível. Observou-se que o resultado deste tipo de quimioterapia não produz bons resultados em pacientes com mesotelioma peritoneal. A boa notícia é que estão ocorrendo pesquisas para encontrar melhores formas de usar a quimioterapia.

No entanto, para os pacientes considerados aptos e cujo mesotelioma peritoneal não avançou, eles podem receber quimioterapia diretamente no abdômen durante a cirurgia citorredutora ou imediatamente após. A medicação é administrada através de uma pequena entrada na barriga. A quimioterapia é administrada por meio de um tubo que é inserido no corte por meio de um tubo também conhecido como cateter. Antes disso, é primeiro aquecido para corresponder à temperatura do corpo. Este processo é conhecido como mesotelioma peritoneal HIIC (quimioterapia intraperitoneal intraperitoneal hipertérmica). Descobriu-se que as pessoas que receberam medicação estavam florescendo aos 5 anos, de acordo com um estudo realizado.

Cuidados paliativos para o tratamento do mesotelioma peritoneal

Muitas vezes o mesotelioma peritoneal é detectado enquanto é bastante progressivo e isso é lamentável. Isto significa que para aqueles que estão demasiado doentes com mesotelioma peritoneal, seria difícil submeter-se a uma quimioterapia completa. Nem toda esperança está perdida para esse tipo de pessoa, porque eles ainda podem tomar medicamentos para aliviar a dor, prevenir a perda de peso e líquidos no abdômen.

Em pacientes com mesotelioma peritoneal, a água é armazenada no abdômen e isso faz com que o estômago inche, o que pode ser desconfortável. Portanto, é fundamental que o líquido seja drenado através de uma torneira ascética ou paracentese abdominal. Este processo deve ser realizado por enfermeiros ou médicos experientes, de preferência aqueles que controlaram sintomas de doença grave de mesotelioma peritoneal no passado. Os cuidados paliativos são necessários e por isso é necessária a inclusão de nutricionista e fisioterapeuta.

Tratamentos alternativos para mesotelioma peritoneal

Embora existam outros métodos de tratamentos alternativos para o mesotelioma peritoneal, o seu resultado é menos esperado. Existe um método conhecido como imunoterapia que estimula o sistema imunológico para que possa auxiliar no combate ao câncer. De acordo com pesquisas, este tratamento se concentra principalmente em como curar o mesotelioma pleural, que é encontrado principalmente no revestimento dos pulmões.

Estágios do mesotelioma peritoneal

  • Mesotelioma peritoneal estágio I:Nesta fase há menos vestígios de tecido canceroso e gânglios linfáticos não infectados pelo cancro. O câncer é controlado no revestimento peritoneal.
  • Mesotelioma peritoneal estágio II:O tecido canceroso nesta fase é modesto. Os gânglios linfáticos e o revestimento peritoneal externo não estão infectados com tumores
  • Mesotelioma peritoneal em estágio III:Este é um estágio perigoso porque o material canceroso está ainda mais disseminado. Os gânglios linfáticos e o revestimento peritoneal externo têm uma grande chance de se espalharem pelo câncer.

Não existe uma quarta etapa, por enquanto, isso ocorre porque o sistema de estadiamento está centrado nos pacientes que chegaram à cirurgia. As pessoas com maior probabilidade de serem classificadas no estágio IV são aquelas que possuem câncer progressivo (aquelas que não chegaram à cirurgia com mesotelioma peritoneal HIPEC (quimioterapia intraperitoneal hipertérmica).

Os sistemas de estadiamento do mesotelioma peritoneal costumavam ser baseados na experiência dos próprios especialistas em câncer. Alguns dos especialistas categorizaram o câncer restrito ao local adequado, como localizado, regional (aquele que se espalhou para os gânglios linfáticos e órgãos próximos) ou distante (estende-se aos órgãos onde o câncer se desenvolveu).

Apesar de os sistemas improvisados ​​serem úteis, o sistema consistente comum a todos os médicos é superlativo.
