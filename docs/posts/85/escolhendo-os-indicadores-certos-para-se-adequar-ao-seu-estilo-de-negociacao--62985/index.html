Escolhendo os indicadores certos para se adequar ao seu estilo de negociação

Investindo

O tipo de indicadores técnicos que os traders escolhem pode ser crucial para o conhecimento analítico que desejam obter no processo. Basicamente, todos os cálculos matemáticos exibem o movimento dos preços dos ativos de uma maneira diferente do que apenas observar as mudanças nos preços. A revisão dos preços de fechamento é uma abordagem comum, mas existem formas mais sutis de avaliar um ativo.

Principais conclusões

  • A média OHLC usa a média do preço de abertura, máximo, mínimo e fechamento (ou último) e é uma configuração de indicador técnico comum em muitas plataformas de negociação.
  • O preço de fechamento é outro indicador comum a ser escolhido, mas usar a média OHLC pode fornecer melhores sinais de negociação, dependendo dos insights que você procura.
  • Experimente entradas de dados e selecione a configuração do indicador que fornece o melhor insight para a estratégia ou método de análise que você está usando.

Como os traders usam indicadores técnicos

Os indicadores técnicos geralmente possuem diversas configurações que podem ser configuradas pelo trader para modificar a forma como os indicadores são exibidos. Esses pontos de dados normalmente correspondem às barras de preço de um gráfico, que são compostas por uma abertura, uma máxima, uma mínima e um fechamento. Quando os traders utilizam um indicador, podem escolher quais destes pontos de dados aplicar nos seus cálculos.

Em vez de usar pontos de dados dessa forma, os traders podem escolher uma configuração que calcule a média de abertura, máxima, mínima e fechamento. Isso também é conhecido como média OHLC. A média alta, baixa e próxima (Média HLC) também é comum em muitas plataformas de negociação. Em algumas plataformas de gráficos e negociação, o preço de fechamento é chamado de "último" preço. O gráfico anexado mostra essas opções no menu de configurações de um indicador. Outras opções também podem ser fornecidas, dependendo do indicador. 

Tipos de indicadores de negociação

O preço de fechamento é uma configuração comum para indicadores, mas pode haver situações em que o uso de abertura, máximo, mínimo ou média forneça uma visão melhor. 

Por exemplo, durante uma tendência de alta, se um trader está observando se as barras de preço caem abaixo de uma média móvel (MA), então usar a mínima de cada vela como entrada para a MA pode fazer mais sentido do que usar o fechamento. Dessa forma, a média móvel só é violada quando uma barra de preço penetra nos mínimos médios de outras barras de preço. O mesmo conceito poderia ser aplicado durante uma tendência de baixa e usando as máximas da barra de preço para calcular a média móvel. Isto não é um requisito, apenas um exemplo de como as configurações podem ser alteradas para alcançar uma visão alternativa. Embora as diferenças sejam muitas vezes pequenas, se um indicador for usado para fornecer sinais comerciais, os dados de entrada terão um impacto direto na lucratividade desses sinais comerciais.

Médias OHLC e HLC

A média de abertura, máxima, mínima e fechamento (OHLC) para um determinado período de tempo é o valor médio do preço de abertura, o preço mais alto atingido, o preço mais baixo atingido e o preço de fechamento. Por exemplo, um castiçal ou barra de preço pode ter uma abertura de 68, uma máxima de 85, uma mínima de 66 e um fechamento de 72.

O cálculo da média de abertura, alta, baixa e fechamento é calculado da seguinte forma:

Média OHLC = (68 + 85 + 66 + 72) / 4 = 72,75

A média HLC é praticamente a mesma, exceto que o preço de abertura é excluído e a soma da máxima, da mínima e do fechamento é dividida por três. 

Média HLC = (85 + 66+ 72) / 3 = 74,33

Embora as médias resultantes sejam comparáveis, isto mostra como a alteração dos parâmetros dos dados introduzidos afeta o cálculo do indicador.

Escolhendo o indicador certo

Experimente configurações diferentes para qualquer indicador que você usar. Selecione as configurações que funcionam melhor para sua análise e estilo de negociação.

Para experimentar os dados de entrada, coloque várias versões do mesmo indicador no mesmo gráfico. Altere os dados de entrada de cada um, para que você possa ver visualmente como os dados de entrada alteram o indicador. Se necessário, altere a cor desses vários indicadores para poder diferenciá-los. Selecione as configurações que fornecem o melhor insight para a estratégia ou método de análise que você está usando.
