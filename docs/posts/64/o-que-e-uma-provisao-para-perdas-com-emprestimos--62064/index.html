O que é uma provisão para perdas com empréstimos?

Empréstimos

Principais conclusões

  • Uma provisão para perdas com empréstimos é uma reserva de caixa que os bancos reservam para cobrir perdas incorridas com empréstimos inadimplentes.
  • Alguns métodos que os bancos têm utilizado para determinar a dimensão das suas reservas para perdas com empréstimos consistem em basear-se em perdas históricas ou utilizar as reservas de outros bancos do setor como orientação.
  • O Texas Ratio mede o valor dos empréstimos inadimplentes de um banco em relação às suas reservas totais para perdas com empréstimos e é calculado dividindo o valor em dólares dos empréstimos inadimplentes de um banco pelo total de seu capital tangível mais suas reservas para perdas com empréstimos.

Definição e exemplos de provisão para perdas com empréstimos

Uma provisão para perdas com empréstimos é uma reserva de caixa que um banco cria para cobrir empréstimos problemáticos que provavelmente não serão reembolsados. Quando um banco espera que um mutuário não cumpra seus empréstimos, a provisão para perdas com empréstimos pode cobrir uma parte ou todo o saldo devedor. Quando um banco estabelece ou contribui com fundos para manter a provisão, o encargo aparece como uma despesa da demonstração de resultados.

  • Nomes alternativos: Reservas para perdas com empréstimos, provisão para avaliação, reserva para avaliação, provisão para perdas com empréstimos

Considere este exemplo: digamos que um banco emitiu um total de $ 100.000 em empréstimos e tem uma provisão para perdas com empréstimos de $ 10.000. Num dos seus empréstimos inadimplentes, o mutuário reembolsou apenas US$ 500 dos US$ 1.000 pendentes. Para cobrir a perda de $ 500 do empréstimo inadimplente, o banco deduziria $ 500 da provisão para perdas com empréstimos.

Como funciona uma provisão para perdas com empréstimos?

De muitas maneiras, uma provisão para perdas com empréstimos serve como um fundo de seguro interno. Ele protege o banco no caso de um mutuário estar inadimplente em seus pagamentos ou inadimplente em todo o empréstimo. Para defender o banco, uma provisão para perdas com empréstimos pode oferecer cobertura para essas perdas incorridas.

Observação

Os bancos dependem de provisões para perdas com empréstimos para se prepararem contra empréstimos problemáticos que podem surgir durante o declínio das condições económicas.

O Banco Comunitário da Baía, por exemplo, aumentou a sua provisão para perdas com empréstimos em resposta à recessão de 2020. O banco aumentou a sua provisão para perdas com empréstimos em US$ 250.000 no terceiro trimestre de 2020 para ajudar na defesa contra possíveis perdas com empréstimos, embora o banco tenha um nível bastante baixo de baixas líquidas.

Num balanço, a provisão para perdas com empréstimos refletiria idealmente os fundos exatos utilizados para cobrir perdas com empréstimos. Os bancos, contudo, nem sempre conseguem prever com precisão quais os empréstimos que não serão reembolsados. Portanto, os bancos analisam o seu perfil de empréstimo para estimar perdas potenciais, o que informaria então o tamanho de uma provisão para perdas com empréstimos. Por outras palavras, uma provisão para perdas com empréstimos representa a previsão de um banco sobre perdas futuras com empréstimos.

No passado, os bancos utilizaram vários métodos para determinar o montante das suas provisões para empréstimos, incluindo:

  • Histórico de perdas: Um banco utiliza o seu histórico de perdas com empréstimos para prever perdas em empréstimos futuros.
  • Análise competitiva: Um banco pode utilizar os relatórios financeiros de outros bancos para estimar um “padrão da indústria” para reservas para perdas com empréstimos. Embora possa não ter em conta as perdas históricas de um banco, pode ajudar um banco a avaliar se as suas reservas para perdas com empréstimos são comparáveis ​​às reservas de outro banco.

Observação

Quando um banco estabelece pela primeira vez uma reserva para perdas com empréstimos ou precisa repor fundos que foram anteriormente esgotados, a cobrança aparece como uma despesa na demonstração do resultado. A categoria de despesas é normalmente denominada “Provisão para perdas com empréstimos”.

Alguns bancos podem optar por dividir as suas reservas para perdas com empréstimos em duas categorias: específicas e gerais. Depois de avaliar os seus empréstimos atuais, um banco pode sinalizar um empréstimo específico ou grupo de empréstimos com perfis de risco mais elevados. Os recursos das reservas específicas são destinados à cobertura desses empréstimos em caso de inadimplência. As reservas gerais destinam-se a quaisquer empréstimos que não requeiram tanta atenção especial.

Proporção Texas

O número de empréstimos inadimplentes de um banco em comparação com suas reservas para perdas com empréstimos é medido com o Texas Ratio. O Texas Ratio é calculado dividindo o valor dos empréstimos inadimplentes de um banco pelo total de seu capital tangível mais suas reservas para perdas com empréstimos.

Quando o montante dos empréstimos problemáticos excede o capital disponível para lidar com as perdas, isso sinaliza que o banco está em apuros. Uma proporção de 1:1, ou 100%, normalmente prevê a falência desse banco.

Acontecimentos notáveis

Durante a crise financeira de 2008, muitos bancos não tinham reservas suficientes para perdas com empréstimos para contabilizar as perdas reais. Nos anos seguintes, os bancos começaram a alocar recursos para aumentar o tamanho das suas reservas para perdas com empréstimos para se defenderem contra o aumento dos empréstimos inadimplentes.

Quando o Congresso aprovou a Lei Dodd-Frank de Reforma e Proteção ao Consumidor de Wall Street (Dodd-Frank) de 2010, um dos seus objetivos era melhorar a estabilidade financeira dos Estados Unidos.Ao abrigo da Lei Dodd-Frank, foram disponibilizadas subvenções para ajudar as instituições financeiras de desenvolvimento comunitário a criar os seus próprios fundos de reserva para perdas com empréstimos, a fim de ajudar a gerir as perdas com empréstimos inadimplentes.

Como resultado da recessão de 2020, muitos bancos revisitaram as suas reservas para perdas com empréstimos para fazer face ao declínio económico. Alguns bancos mais do que duplicaram as suas reservas.No segundo trimestre de 2020, as provisões para perdas com empréstimos bancários, no total, totalizaram 242,79 mil milhões de dólares – ligeiramente abaixo dos 263,11 mil milhões de dólares no primeiro trimestre de 2010, após a Grande Recessão.
