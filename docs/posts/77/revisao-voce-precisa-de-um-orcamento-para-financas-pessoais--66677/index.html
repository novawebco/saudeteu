Revisão: você precisa de um orçamento para finanças pessoais

Orçamento

You Need A Budget (YNAB) é um software de finanças pessoais com fortes recursos de orçamento financeiro. O software funciona em computadores Windows ou Mac e possui uma versão mobile para verificar seu orçamento e inserir transações quando você não estiver usando o computador. Os aplicativos móveis sincronizam as transações inseridas em seu smartphone ou tablet com o software de desktop usando Cloud Sync. 

Recursos de software

O software YNAB foi apresentado em um formato fácil e intuitivo. A ferramenta de transações programadas é recolhida, a menos que você queira usá-la, e as contas usadas para orçamento, fora do orçamento e contas encerradas são recolhidas na barra lateral.

O software mostra informações orçamentárias consolidadas no início de cada mês, e o YNAB possui um recurso de salvamento automático que salva os dados com frequência. Você também pode restaurar seu orçamento para versões anteriores se cometer um erro. Outros recursos incluem:

  • Impressão fácil
  • Alternar entre vários orçamentos sem reiniciar
  • Assistente de reconciliação de conta
  • Nenhuma transação duplicada com importação de arquivo QIF
  • Exportação de dados flexível aprimorada
  • Novos relatórios que detalham facilmente os detalhes

Ferramentas Fortes

O YNAB é baseado na ideia de que você deve ter economias reservadas para usar quando surgirem despesas inesperadas, e o software ajuda você a construir esse colchão financeiro e a se livrar de dívidas.

Os detalhes na parte superior de cada coluna do mês na tela de orçamento mostram o dinheiro que não foi gasto e acumulado do mês anterior, o total gasto em excesso em todas as categorias de gastos no mês anterior, a receita recebida até o momento no mês atual e o valor total orçado no mês atual.

Para manter essas informações úteis, você precisará inserir ou baixar transações a cada poucos dias ou, no mínimo, uma vez por semana.

Sincronização na nuvem

YNAB salva automaticamente as alterações enquanto você trabalha no software usando Cloud Sync. Este recurso requer uma conta gratuita do Dropbox, e você pode compartilhar dados em todos os seus computadores e usar o YNAB em qualquer computador Windows ou Mac que você possua. Esses backups também possibilitam reverter facilmente para dados anteriores se você errar alguma coisa.

Relatórios

O YNAB não oferece muitos relatórios, mas inclui opções decentes para personalizar os dados por período, categorias de orçamento, beneficiários e contas. Oferece relatórios prontos, incluindo Gastos por Categoria, Gastos por Beneficiário, Receita x Despesa e Patrimônio Líquido. Você pode clicar nas fatias de um gráfico de pizza para obter informações mais detalhadas e pode imprimir os relatórios e exportar os dados do relatório para outros programas, como o Microsoft Excel.

Preços YNAB

YNAB possui um plano de baixo custo; se você optar pelo pagamento mensal, custa US$ 11,99 por mês, mas você pode adquirir o plano anual por US$ 84 por ano. Eles também oferecem um teste gratuito de 34 dias para novos usuários, para que você possa testar o software antes de se comprometer financeiramente. Para estudantes universitários, você pode usar o YNAB gratuitamente; basta fazer o upload do comprovante de matrícula escolar e a empresa isentará de suas taxas.
