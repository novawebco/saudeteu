Como você testa o linfoma não-Hodgkin?

Câncer

Muitos pacientes vão ao médico com umalinfonodo inchado/s com outros sintomas. Seu médico fará um histórico completo e examinará você completamente. O teste relevante será solicitado para fazer um diagnóstico.

Como você testa o linfoma não-Hodgkin?

Teste de biópsia para linfoma não-Hodgkin

A biópsia é o teste definitivo para confirmar ou descartar linfoma não-Hodgkin (LNH). Um pequeno pedaço ou todo o linfonodo será retirado para teste. A razão comum para um linfonodo inchado é uma infecção, então seu médico pode prescrever medicamentos para curar a infecção. Se o(s) linfonodo(s) não desaparecer(em), seu médico poderá solicitar uma biópsia. Se sua história e exame dos gânglios linfáticos sugerirem uma malignidade/linfoma, seu médico poderá solicitar uma biópsia imediatamente.

Biópsia Excisional ou Incisional:Este é o tipo de biópsia preferido para diagnosticar linfoma não-Hodgkin. Quase sempre fornece amostra adequada para fornecer resultados precisos.

  • Excisional – todo o linfonodo é cortado e retirado
  • Incisional – uma pequena parte do linfonodo afetado é cortada

Se o linfonodo estiver logo abaixo da pele, o procedimento pode ser feito com anestesia local. Mas se o linfonodo afetado estiver profundamente no tórax ou abdômen, o procedimento deverá ser feito com sedação profunda ou anestesia geral por meio de tomografia computadorizada ouultrassomdigitalize para direcionar a agulha.

Biópsia por agulha:As biópsias por agulha são menos invasivas do que as biópsias excisionais ou incisionais; o problema é que uma amostra adequada pode não estar presente para diagnosticar e estadiar o linfoma não Hodgkin. Portanto, biópsias por agulha não são comumente feitas para diagnosticar linfoma não-Hodgkin. Mas o seu médico pode fazer uma biópsia por agulha se achar que é devido a uma infecção. Existem 2 tipos principais de biópsias por agulha:

  1. Biópsia por Aspiração por Agulha Fina (PAAF) –uma agulha muito fina presa a uma seringa é usada para retirar pequenas quantidades de tecido do linfonodo.
  2. Biópsia com agulha central –uma agulha grande é usada para retirar um pedaço muito maior de tecido do linfonodo.

Teste de imagem para linfoma não-Hodgkin

Os exames de imagem são feitos por diversos motivos, os motivos são:

  • Para determinar o estágio do linfoma não-Hodgkin
  • Para verificar se o tratamento está funcionando
  • Para determinar a causa de certos sintomas comofalta de ar,dor no peito
  • Para verificar se o linfoma não-Hodgkin é recidivante

PeitoRaio X: Para verificar se há gânglios linfáticos aumentados na área.

Tomografia Computadorizada (TC): Pode detectar gânglios linfáticos ou órgãos aumentados. É útil na detecção de linfoma não-Hodgkin no tórax, abdômen, pelve, cabeça e pescoço

Ultrassonografia:É útil para detectar gânglios linfáticos aumentados logo abaixo da pele, no abdômen e para detectarfígado aumentado, baço e rim.

Tomografia por emissão de pósitrons (PET):A PET/CT é mais precisa na detecção do linfoma não-Hodgkin do que apenas a tomografia computadorizada. A PET scan pode ser útil em:

  • Para ver se os gânglios linfáticos aumentados contêm linfoma não-Hodgkin
  • Se o linfoma não-Hodgkin estiver respondendo ao tratamento
  • Encontre pequenas áreas que possam ser linfoma não-Hodgkin que possam parecer normais em uma tomografia computadorizada.

Exame de sangue para linfoma não-Hodgkin

Os exames de sangue não são úteis no diagnóstico do linfoma, mas podem ajudar a determinar o quão avançado está o linfoma não-Hodgkin.

  • Hemograma completo – um paciente diagnosticado com linfoma não-Hodgkin, contagens sanguíneas baixas significa que o linfoma está crescendo e afetando a medula óssea.
  • Lactato Desidrogenase – os níveis são frequentemente aumentados em pacientes com linfoma não-Hodgkin
  • Testes de Função Hepática/Função Renal – para detectar a função

Resumo

Existem vários testes que podem ser feitos para o linfoma não-Hodgkin (LNH), mas o teste confirmativo para diagnosticar o linfoma não-Hodgkin é uma biópsia incisional ou excisional do linfonodo aumentado. Isso pode indicar o tipo e o estágio do linfoma não-Hodgkin. Outros métodos de biópsia incluem biópsias por agulha que não são muito precisas. Estudos de imagem podem ser feitos para determinar o estágio do linfoma não-Hodgkin, para verificar se o tratamento está funcionando, para determinar a causa de certos sintomas como falta de ar, dor no peito e para verificar se o linfoma está recidivando. O exame de sangue também pode ser feito para determinar a complexidade do linfoma não-Hodgkin.
