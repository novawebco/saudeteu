O que é uma nota municipal?

Investindo

Uma nota municipal é um financiamento de curto prazo que um governo estadual ou local utiliza, muitas vezes para cobrir deficiências de receitas. As notas municipais são garantidas por fontes de receitas futuras previstas, tais como cobranças de impostos ou rendimentos de títulos.

Definição e Exemplos de Notas Municipais

Os governos estaduais ou locais emitem instrumentos de dívida na forma de notas municipais que normalmente são reembolsadas no prazo de um ano.Estas dívidas são garantidas por fontes de receitas esperadas – normalmente receitas fiscais, mas também podem incluir receitas de obrigações, fundos de subvenções federais ou receitas geradas a partir de uma infra-estrutura ou serviço público. As notas municipais são frequentemente utilizadas para cobrir necessidades de curto prazo, tais como alívio de fluxo de caixa ou financiamento provisório para projetos de capital.

  • Nome alternativo:Notas municipais

Por exemplo, uma nota municipal pode ser usada para iniciar um projeto público. Enquanto aguarda a arrecadação de impostos, emite notas municipais para cobrir os custos iniciais. Quando os impostos são recolhidos posteriormente, eles são utilizados para reembolsar as notas municipais. O município obteria então financiamento de longo prazo para cobrir os custos contínuos durante a duração do projeto.

Como funciona uma nota municipal?

Os governos estaduais ou locais normalmente emitem notas municipais durante períodos de fluxo de caixa restrito. Isto ocorre normalmente quando surgem despesas do Estado mas não há receitas suficientes a entrar ou estas devem ser cobradas numa data posterior. Durante estas quebras de receitas por vezes imprevistas, o governo vendia dívida sob a forma de notas municipais de curto prazo para angariar os fundos necessários. 

As notas municipais são reembolsadas com fontes de receitas futuras, tais como receitas fiscais ou rendimentos de títulos. Quando o órgão emissor recebe essa receita, ela é utilizada para liquidar as notas municipais pendentes. As notas municipais são frequentemente classificadas pela fonte de receita utilizada para o reembolso. As notas reembolsadas com impostos futuros, por exemplo, são chamadas de notas de antecipação de impostos (TANs).

Observação

Ao contrário dos títulos municipais, que podem vencer em vários anos, as notas municipais têm prazos curtos – normalmente até 12 meses. 

Devido aos seus prazos mais curtos, as notas municipais muitas vezes financiam custos de curto prazo, como capital de giro e despesas operacionais. As notas municipais também podem ser usadas como financiamento provisório. O governo, por exemplo, pode contar com notas municipais para financiar os custos iniciais de um grande projecto até que o financiamento a longo prazo possa ser obtido.

Considere este exemplo recente da Califórnia. As suas agências de educação locais normalmente recebem metade das receitas esperadas do estado. Quando estes pagamentos são diferidos, isso pode criar problemas de fluxo de caixa. Para se proteger contra escassez temporária de fluxo de caixa, o Programa de Reserva de Dinheiro Escolar da Califórnia foi criado para coletar notas de antecipação de receitas fiscais.Isto permite que as agências de educação tomem emprestado o dinheiro de que necessitam e o devolvam após receberem os pagamentos diferidos do estado. 

Tipos de Notas Municipais

Sob a égide das notas municipais, existem vários tipos de títulos emitidos pelo município, incluindo:

  • Notas de antecipação de impostos
  • Notas de antecipação de títulos
  • Notas de antecipação de concessão
  • Notas de antecipação de receita

Notas de Antecipação Fiscal

Os governos estaduais e locais emitem notas de antecipação de impostos (TANs) para arrecadar fundos antes que as receitas fiscais sejam cobradas. Quando a receita fiscal é cobrada, ela é então usada para liquidar os TANs. 

Os governos locais foram autorizados a emitir TANs em resposta à emergência de saúde pública que começou no início de 2020 para cobrir diferimentos de vencimentos de impostos, quebras de receitas e despesas relacionadas com a emissão de TANs.

Notas de antecipação de títulos

As notas de antecipação de títulos (BANs) devem ser reembolsadas com os rendimentos obtidos com títulos de longo prazo. Os prazos são um pouco mais longos do que outros tipos de notas municipais – às vezes até dois anos. 

Observação

As notas de antecipação de títulos são normalmente usadas como financiamento provisório, como financiamento inicial para um projeto financiado pelo estado.

Notas de antecipação de concessão

Notas de antecipação de doações (GANs) são veículos de dívida de curto prazo que são reembolsados ​​com fundos obtidos de compromissos de doações por uma agência de doações estadual ou federal. As agências de trânsito, por exemplo, podem emitir GANs, que serão reembolsados ​​com fundos futuros das subvenções do Título 49 da Administração Federal de Trânsito.

Notas de antecipação de receita

As notas de antecipação de receitas (RANs) são semelhantes às notas de antecipação de impostos, exceto que as notas são reembolsadas com receitas que não sejam impostos. As fontes de receita podem incluir fundos arrecadados de projetos públicos, como estádios, aeroportos, metrôs e pontes.

Notas Municipais vs. Títulos Municipais

O que isso significa para investidores individuais

Algumas notas municipais são isentas de impostos e são emitidas em valores de US$ 5.000.Como as notas municipais normalmente expiram dentro de um ano, o principal mais os juros são pagos no vencimento.

Os investidores podem adquirir notas municipais no mercado primário ou secundário. O mercado primário é onde novas emissões de títulos e notas estão disponíveis. O mercado secundário é uma rede na qual os revendedores compram e vendem títulos e notas municipais antes de atingirem o vencimento. Como as notas municipais podem ser vendidas antes do vencimento, são consideradas ativos bastante líquidos.

Principais conclusões

  • Uma nota municipal é uma obrigação de dívida de curto prazo emitida por um governo estadual ou local e normalmente é reembolsada dentro de um ano.
  • As notas municipais são garantidas por fontes de receitas futuras, tais como receitas fiscais, rendimentos de títulos e fundos de subsídios.
  • As notas municipais são normalmente utilizadas para aliviar temporariamente as crises de fluxo de caixa ou para fornecer financiamento provisório até que o financiamento de longo prazo possa ser obtido.
