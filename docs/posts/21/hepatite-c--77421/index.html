Hepatite C

Saúde

A hepatite C é uma doença infecciosa do fígado causada pelo vírus da hepatite C (HCV). Nos Estados Unidos, é a infecção transmitida pelo sangue mais comum, afetando cerca de 2,4 milhões de americanos, ou cerca de 1% da população adulta. A hepatite C geralmente é transmitida pelo contato com sangue infectado ou transmitida de mãe para filho durante a gravidez.O vírus pode desaparecer espontaneamente em algumas pessoas, tornar-se uma infecção persistente em outras e evoluir para uma doença potencialmente fatal em outras.
