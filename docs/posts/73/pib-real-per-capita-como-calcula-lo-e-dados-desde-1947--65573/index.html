PIB real per capita, como calculá-lo e dados desde 1947

Economias dos EUA e do mundo

O PIB real per capita é uma medida da produção econômica total de um país dividida pelo número de pessoas e ajustada pela inflação. É usado para comparar o padrão de vida entre países e ao longo do tempo.

Este indicador econômico consiste nos três conceitos a seguir. Você deve entendê-los primeiro se quiser compreender o PIB per capita.

O primeiro conceito é “produto interno bruto”. Isso mede tudo o que um país produz num ano. Os componentes do PIB são consumo pessoal, investimento empresarial, gastos do governo e exportações menos importações.O Bureau of Economic Analysis relata trimestralmente, atualizando sua estimativa a cada mês. 

O segundo é o “PIB real”, que é o PIB sem o efeito das mudanças de preços. A inflação aumenta o PIB regular e “nominal”, de modo que o PIB real é uma medida mais precisa quando se deseja comparar uma economia ao longo do tempo.

A terceira é “per capita”, que significa “por pessoa”. O PIB real é dividido pela população de um país para calcular o PIB real per capita. É a melhor maneira de comparar indicadores económicos como o PIB de países com tamanhos populacionais muito diferentes. 

Fórmula do PIB real per capita

A fórmula do PIB real per capita depende dos dados disponíveis. Vamos começar com o mais simples. Se você já conhece o PIB real (R), então divida-o pela população (C):

R/C = PIB real per capita.

Nos Estados Unidos, o Bureau of Economic Analysis calcula o PIB real usando 2012 como ano base.Se você não conhece o PIB real, poderá calculá-lo a partir do PIB nominal (N) se conhecer o deflator de preços implícito (D). O deflator é a razão entre quanto custariam os bens e serviços hoje se não tivesse havido inflação desde o ano base. É semelhante a outra medida de inflação, o Índice de Preços ao Consumidor. Seus componentes têm pesos diferentes.

Felizmente, o BEA fornece o deflator para 2012 na Tabela 1.1.9.Aqui está a fórmula para calcular o PIB real per capita (R) se você conhece apenas o PIB nominal (N) e o deflator (D):

(N/D) / C = PIB real per capita

Perguntas frequentes (FAQ)

O que causaria uma queda no PIB real per capita se o PIB real crescesse a uma taxa constante?

Se a população crescer demasiado rapidamente, isso poderá causar uma queda no PIB real per capita. Se o PIB real crescer, mas a população crescer a um ritmo mais rápido, então o PIB real per capita diminuirá.

Que fase do ciclo económico corresponde ao declínio do PIB real?

Quando o PIB real diminui, marca a fase de contracção do ciclo económico.Isso continua até que o vale marque o fundo da contração. Após o ponto mais baixo, o aumento do PIB real marca o início da fase de expansão.
