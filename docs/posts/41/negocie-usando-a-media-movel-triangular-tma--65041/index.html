Negocie usando a média móvel triangular – TMA

Investindo

Na negociação de ações, a média móvel triangular (TMA) é um indicador técnico semelhante a outras médias móveis. O TMA mostra o preço médio (ou médio) de um ativo em um número específico de pontos de dados – geralmente um número de barras de preço. No entanto, difere porque é suavizado duas vezes, o que também significa uma média duas vezes.

Uma média móvel triangular pode ser calculada usando vários dados de entrada, como preços, volume ou outros indicadores técnicos. As médias móveis triangulares são mais frequentemente aplicadas aopreçode um ativo. A média móvel se sobrepõe às barras de preço em um gráfico. Também pode sobrepor o indicador de volume se for aplicado ao volume ou a qualquer outro indicador escolhido pelo trader.

Principais conclusões

  • A média móvel triangular (TMA) mostra o preço médio de um ativo em um número específico de pontos de dados – geralmente um número de barras de preço.
  • O objetivo do TMA é suavizar duplamente os dados de preços, o que produzirá uma linha que não reage tão rapidamente como faria uma média móvel simples. 
  • A TMA não reagirá rapidamente em condições voláteis de mercado, o que significa que levará mais tempo para a sua linha TMA mudar de direção.

Cálculo da média móvel triangular

A média móvel triangular (TMA) é uma média de uma média dos últimos N preços (P).

Primeiro, calcule a média móvel simples (SMA):

    SMA = (P1 + P2 + P3 + P4 + ... + PN) /N

Em seguida, calcule a média de todos os valores de SMA para obter os valores de TMA.

    TMA = (SMA1 + SMA2 + SMA3 + SMA4 +...SMAN)/N

O TMA também pode ser expresso como: TMA = SUM (valores SMA) / N

Felizmente, você não precisa calcular nada; software de negociação e pacotes de gráficos analisam todos os números para você.

Nem todas as plataformas gráficas possuem um indicador TMA. Para ver se o seu funciona, abra um gráfico e vá para seus indicadores. Procure por "Média Móvel Triangular". Se não estiver lá, tente aplicar uma média móvel normal (MA), depois vá para a configuração da MA e veja se você pode alterar seu cálculo para triangular. Algumas plataformas também rotulam o TMA como “Média Móvel Triangular” ou “MovAvgTriangular”.

Outra opção é aplicar um SMA (1) ao seu gráfico e depois aplicar outro SMA (2), que usa SMA (1) como entrada.

Usos de negociação de média móvel triangular

O objetivo da média móvel triangular é suavizar duplamente os dados de preços, o que produzirá uma linha em seu gráfico que não reage tão rapidamente quanto um SMA faria. Pode ser vantajoso ou problemático, dependendo da finalidade para a qual você está usando o TMA. 

A TMA não reagirá rapidamente em condições voláteis de mercado, o que significa que levará mais tempo para sua linha de TMA mudar de direção. Se você estiver usando o TMA como sinal de negociação, o TMA poderá reagir muito lentamente.

As defasagens do TMA podem ser um benefício. Se o preço oscilar para frente e para trás (intervalo), o TMA não reagirá tanto, informando assim que a tendência não mudou. É necessário um movimento mais sustentado no preço para fazer com que o TMA mude de direção. 

Se você deseja uma média móvel que responda rapidamente às mudanças de preço, o TMA não é o ideal. Uma média móvel ponderada frontal, uma média móvel exponencial (EMA) ou mesmo uma SMA é provavelmente uma escolha melhor se você estiver procurando uma média móvel responsiva. O TMA é uma boa escolha se você deseja um indicador que não reaja tanto ou com tanta frequência às mudanças de preço. 

Palavra final sobre a média móvel triangular

Um TMA é uma média de uma média, criando uma linha em seu gráfico que normalmente se move em ondas mais constantes e mais longas do que um SMA. O cálculo do TMA é a SOMA dos valores do SMA, dividido pelo número de períodos que você deseja calcular a média. A TMA reage mais lentamente às mudanças de preço do que outras médias móveis, como a EMA e a SMA. Às vezes, pode mantê-lo na tendência por mais tempo, produzindo lucros maiores. Mas quando a tendência mudar, o TMA reagirá lentamente, o que pode significar que você desistirá dos lucros (poderia ter saído mais cedo com outro indicador).

Não existe um indicador perfeito ou média móvel. É tudo uma questão de como você o usa. Teste você mesmo o TMA antes de utilizá-lo com capital real. Durante o teste, use várias configurações e veja se o indicador o ajuda a tomar melhores decisões de negociação.
