Variedades de cereja azeda

Frutas
As cerejas azedas são ótimas para cozinhar. Eles são ricamente saborosos e de polpa firme para que não fiquem moles durante o cozimento. Use cerejas ácidas para tortas, sapateiros, clafoutis, molhos para sobremesas, conservas e geleias. Existem dois tipos de cerejas ácidas: as cerejas do tipo amarelle são de polpa amarela com suco claro; As cerejas do tipo Morello têm a polpa vermelha com suco vermelho. As cerejas frescas - existem mais de 300 variedades - chegam ao mercado de meados de junho a meados de agosto. Aqui estão algumas variedades de cereja azeda a considerar: Richmond precoce: uma cereja pequena, redonda e vermelha com um sabor ácido. Esta é uma cereja tipo amarelle usada para fazer doces, tortas, geléias e conservas. Colheita antecipada. Morello inglês: uma cereja com casca vermelho-negra profunda que é grande, macia e suculenta. Esta cereja tipo Morello é ligeiramente azeda. Congela bem e é uma excelente opção para tortas. Colheita tardia. Meteoro: uma cereja grande, de pele vermelha clara, com polpa amarela que é levemente ácida; tipo amarelle. Colheita tardia. Montmorency: considerada a melhor cereja para torta, é uma cereja redonda de casca vermelha brilhante de tamanho médio a grande, polpa amarela macia e sabor azedo levemente ácido. Montmorency (em homenagem a um vale na Ile-de-France) pode ser enlatado. É uma cereja tipo amarelle. Colheita antecipada. Estrela do Norte: semelhante a Montmorency com pele vermelha brilhante a mogno e polpa vermelha suculenta. Cereja tipo Morello. Colheita tardia.
