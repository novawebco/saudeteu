Beriliose: causas, sintomas, diagnóstico, tratamento, prevenção

Dor no peito

O que é beriliose?

A beriliose, conforme declarado, é um distúrbio pulmonar ocupacional causado em pessoas que trabalham com um elemento chamado berílio. Este elemento é normalmente encontrado em rochas, poeira vulcânica, carvão, etc. e é utilizado em algumas indústrias. A beriliose geralmente se desenvolve em indivíduos sensíveis ao berílio.

A beriliose pode ser de 2 tipos – aguda e crônica

Beriliose Aguda:Este tipo de beriliose é causado por exposição limitada e é um fenômeno muito raro nos dias de hoje.

Beriliose crônica:Este tipo de beriliose é causado após exposição prolongada ao berílio. Este tipo de beriliose é mais comum que a forma aguda de beriliose.

Quais são as causas da beriliose?

A beriliose, conforme declarado, é causada pela exposição ao elemento berílio. A beriliose geralmente é encontrada em pessoas sensíveis a esse elemento. Alguns dos fatores de risco para o desenvolvimento de Beriliose são o envolvimento nas seguintes indústrias:

  • Aeroespacial
  • Eletrônica
  • Fibra óptica
  • Mineração
  • Reatores nucleares
  • Sucata de metal
  • Fabricação de espelhos, microondas etc.

Quais são alguns dos sintomas da beriliose?

Os sintomas da beriliose geralmente são causados ​​​​por uma inflamação grave dos pulmões. Esses sintomas são:

  • Tosse produtiva
  • Dor no peito
  • Falta de ar
  • Perda de peso
  • Fadiga.

Como a beriliose é diagnosticada?

Para diagnosticar a beriliose, o médico assistente perguntará sobre os sintomas e, especificamente, sobre a história ocupacional do indivíduo. Para diagnosticar a beriliose, o indivíduo afetado precisa ser exposto ao berílio. Um teste denominado Teste de Proliferação de Linfócitos de Berílio será positivo. Haverá presença de granulomas quando uma biópsia pulmonar for realizada.

Alguns dos outros testes para confirmar o diagnóstico do teste de proliferação de linfócitos de berílio são:

  • Radiografia de tórax
  • Teste de Função Pulmonar.

Quais são os tratamentos para a beriliose?

A base para o tratamento da beriliose é interromper a exposição adicional ao berílio. Para tratar a beriliose, umcorticosteróidepode ser administrado para diminuir a inflamação. A beriliose é definitivamente tratável se os sintomas forem identificados e o tratamento for iniciado precocemente.

Quais são as maneiras de prevenir a beriliose?

Algumas medidas para prevenir a beriliose incluem:

  • Manter ventilação adequada no local de trabalho
  • Use uma máscara facial para evitar a exposição ao berílio.
  • Não se deve comer, beber ou fumar em áreas onde o berílio está sendo usado.
  • Nunca se deve usar roupas normais no local de trabalho e o empregador deve fornecer roupas de trabalho para proteção
  • Após o trabalho deve-se tomar um banho antes de voltar a vestir a roupa habitual.
