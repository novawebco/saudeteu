Posso transferir ativos IRA SIMPLES para um plano 401 (k)?

Investindo

A maioria das pessoas muda de emprego e empregador várias vezes ao longo de suas carreiras. Aqueles que participaram num plano de reforma patrocinado pelo empregador, como um Plano de Equiparação de Incentivo à Poupança para Funcionários (SIMPLE) IRA ou um plano 401(k), enfrentam a necessidade de descobrir o que fazer com os activos acumulados no plano quando seguirem em frente.

A retirada dos ativos provavelmente exigiria que você pagasse impostos sobre valores não tributados, mas geralmente você tem três outras opções para lidar com ativos 401 (k) no plano de um antigo empregador. Você pode deixá-los no plano ou transferi-los, transferindo-os para um IRA de prorrogação ou 401 (k) de um novo empregador ou outro plano de aposentadoria qualificado.

As regras são ligeiramente diferentes para ativos SIMPLE IRA, entretanto. Você pode transferir legalmente seus ativos SIMPLES IRA para um plano 401 (k), mas a transferência depende do tempo se seu objetivo for evitar impostos.

Principais conclusões

  • Um Plano de Equiparação de Incentivo à Poupança para Funcionários (SIMPLE) IRA é um tipo especial de plano de aposentadoria patrocinado pelo empregador para pequenas empresas.
  • Você pode transferir um IRA SIMPLES para outro plano qualificado se tiver participado por pelo menos dois anos. Caso contrário, é um saque e não um rollover.
  • O tratamento fiscal da rolagem será determinado pela data da rolagem

Visão geral dos IRAs SIMPLES

Um SIMPLE IRA é um plano de aposentadoria patrocinado pelo empregador que permite que empregadores e funcionários contribuam para IRAs individuais estabelecidos para cada funcionário do plano. Esses planos geralmente estão disponíveis para pequenas empresas com 100 funcionários ou menos.

Um IRA SIMPLES funciona como um cruzamento entre um IRA tradicional e um plano 401 (k). Seu empregador é obrigado a fazer contribuições para um IRA SIMPLES em seu nome. A contribuição deve corresponder a até 3% da sua remuneração (sem limite de remuneração) ou deve ser uma contribuição não eletiva para cada funcionário elegível. Neste caso, pode ascender a 2% da sua remuneração até ao limite de remuneração anual de $305.000 em 2021 ($290.000 em 2021).

Como funcionário, você também pode optar por fazer contribuições para redução de salário para um SIMPLES IRA. Você pode contribuir com um máximo de $ 13.500 de seu salário para um SIMPLES IRA em 2021 se tiver menos de 50 anos, aumentando para $ 14.000 em 2022. Você pode contribuir com $ 3.000 extras se tiver 50 anos ou mais.

Observação

As contribuições que você faz para o plano são sempre integralmente adquiridas. Isso significa que você sempre terá a propriedade deles.

Os empregadores podem deduzir suas contribuições para um IRA SIMPLES e os funcionários podem excluir suas contribuições de sua renda bruta.

Limitando impostos com uma simples rolagem de IRA

Normalmente, você pagará imposto de renda sobre os saques feitos em seu plano SIMPLE IRA. Você terá que pagar uma multa adicional de 10% se fizer saques antes de atingir a idade de 59 anos e meio, a menos que se qualifique para uma exceção, como se você tiver uma deficiência ou receber o saque como uma anuidade.

Você pode evitar qualquer uma dessas perdas financeiras se transferir seus ativos SIMPLES IRA para um 401 (k) ao deixar seu empregador. Sua idade também não é um fator neste caso, porque o acúmulo não é considerado um saque quando você o cronometra corretamente.

Regras para transferências SIMPLES de IRA para planos 401 (k)

Transferir seus ativos SIMPLES IRA para um 401 (k) é simples. Mas você deve concluir a rolagem dentro dos termos do seu plano SIMPLE IRA e das regras do IRS para garantir que a rolagem se qualifique como isenta de impostos e penalidades.

Você só pode fazer uma transferência isenta de impostos de um IRA SIMPLES para um 401 (k) após um período de dois anos. O relógio começa a contar a partir da data em que você participou pela primeira vez do plano, e não a partir da data em que deixou seu empregador.

Você terá que pagar impostos se não cumprir esta regra de dois anos. O valor será tratado como saque se ocorrer dentro do período de dois anos e você transferir seus ativos SIMPLES para um plano 401(k). Você terá que incluir a retirada em seu lucro tributável daquele ano.

Você também pode estar sujeito a uma penalidade maior relacionada à idade. A multa de 10% que você pagaria se tivesse menos de 59 anos e meio aumenta para 25% se você transferir seu SIMPLES IRA dentro do período de dois anos, a menos que você se qualifique para uma exceção. A mudança de emprego em si não é considerada uma exceção. No entanto, você pode se qualificar para uma exceção se o valor retirado for menor do que o valor que você paga pelo seguro saúde enquanto estiver desempregado.

Observação

Seu SIMPLES IRA deve estar em vigor por pelo menos dois anos a partir da data de participação no plano para se qualificar para uma transferência isenta de impostos para 401 (k).

Rollovers de IRA SIMPLES para outro IRA SIMPLES

Outra forma de realizar uma rolagem isenta de impostos é transferir ativos de seu SIMPLES IRA para outro SIMPLES IRA, se você não puder esperar dois anos. Você é livre para transferir qualquer quantia de um SIMPLE IRA para outro SIMPLE IRA em uma transferência isenta de impostos de administrador para administrador durante o período de dois anos ou depois. O IRS não faz você esperar dois anos para fazer esse tipo de transferência.

Observação

Você só pode fazer uma transferência de IRA para IRA por período de 12 meses, então você teria que esperar até o ano seguinte para transferir seu IRA SIMPLES para outro IRA SIMPLES se já tiver concluído uma transferência dentro deste prazo.

Rollovers IRA SIMPLES para um Roth IRA

A regra de dois anos também se aplica a rolagens para Roth IRAs, mas com uma desvantagem significativa: a rolagem não será isenta de impostos. Qualquer parte do plano que represente renda não tributada para você deve ser incluída em sua renda quando você apresentar a declaração de imposto de renda daquele ano.

O resultado final

Você pode transferir legalmente ativos SIMPLES IRA para um plano 401 (k), mas o tratamento fiscal da rolagem será determinado pela data de rolagem. Aguarde dois anos a partir da data de participação no plano antes de realizar a rolagem para 401 (k) se quiser evitar o pagamento de impostos. Ou você pode mover os ativos para outro IRA SIMPLES a qualquer momento.
