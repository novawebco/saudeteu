Como preparar um molho de sal de Epsom para o fungo das unhas dos pés

Antes de preparar um pé de molho, você precisa ter o tipo certo de embarcação. Existem algumas opções diferentes para você mergulhar os pés. Para muitas pessoas, uma simples bacia para os pés ou até uma tigela grande funcionam bem. Desde que seus pés possam estar totalmente submersos em água morna, qualquer bacia servirá. Mas, para quem deseja obter benefícios extras, existem máquinas de banho para pés e spa . Algumas das melhores máquinas de banho para pés e spa trabalham para oferecer relaxamento. Eles adicionam coisas como bolhas oxigenadas ou jatos de massagem. Isso ajuda na circulação e na saúde geral dos seus pés. Depois de decidir que tipo de máquina de lavatório ou spa para pés é ideal para você, você pode preparar o seu pé. Siga estas etapas simples para obter os melhores resultados:
  1. Preparação para os pés. Seus pés devem estar limpos e livres de loções antes de colocá-los de molho. Verifique se as unhas dos pés estão cortadas razoavelmente curtas. Pode ser necessário usar um par de tosquiadeiras grossas para fazer o trabalho.
  2. Encha uma bacia ou banho de pés com água morna (não quente). Deve haver o suficiente para cobrir completamente os pés.
  3. Adicione até ½ xícara de sais de Epsom na água morna e mexa com as mãos até que ela se dissolva.
  4. Mergulhe os pés por 30 a 60 minutos. Algumas pessoas acham mais vantajoso tomar dois banhos de 20 a 30 minutos por dia, em vez de um longo banho. Tente molhar os pés de manhã e à noite para obter melhores resultados.
  5. Quando terminar, seque bem os pés. É importante ficar entre os dedos para garantir que o fungo não tenha um excelente ambiente para se espalhar. Depois de secar os pés com uma toalha, deixe-os secar ao ar o maior tempo possível. Coloque apenas meias ou sapatos quando os pés estiverem completamente secos.
