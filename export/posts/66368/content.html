A versão completa do software de finanças pessoais Microsoft Money foi descontinuada em 2009, substituída por um download gratuito chamado Money Plus Sunset Deluxe.﻿﻿﻿﻿ Embora este software substituto funcione para tarefas básicas de gerenciamento de dinheiro, ele não inclui suporte técnico nem quaisquer recursos que exijam conectividade com a Internet.

Se você deseja substituir o Microsoft Money por algo que tenha mais recursos e flexibilidade do que o Money Plus Sunset Deluxe, aqui estão algumas opções.

Opção 1: software para desktop

Se você gosta de usar software de desktop para gerenciar suas finanças, terá muitas alternativas para escolher. A maioria deles vem com uma avaliação gratuita, portanto não custará nada experimentar para descobrir o que funciona melhor para você. Aqui estão algumas opções:

  • Dança do dinheiro:Você pode baixar uma versão deste software para sistemas operacionais Mac, Windows ou Linux. Uma versão do aplicativo também está disponível para dispositivos iOS e Android.
  • Quicken: Este programa oferece mais poder e flexibilidade para usuários de software de finanças pessoais. Um recurso de orçamento muito aprimorado e um rastreamento mais fácil de empréstimos são duas das melhorias. Você pode baixá-lo para Windows ou Mac e há um aplicativo móvel para iOS e Android.
  • AceMoney: Afirmando ser a melhor alternativa ao Quicken, o AceMoney é uma alternativa forte, embora não ofereça pagamento de contas on-line ou downloads de transações.
  • Pináculo do dinheiro:Os dados financeiros pessoais no Moneyspire podem ser compartilhados entre vários usuários em um computador ou em uma rede, e os dados funcionam com as versões Mac e Windows do software.
  • GnuCash:Graças ao movimento do software de código aberto, o GnuCash é gratuito. Este software financeiro pode ser usado para monitorar finanças pessoais e também funciona muito bem como software de contabilidade para pequenas empresas. O GnuCash rastreia uma variedade de tipos de contas, ações, receitas e despesas.

Opção 2: Software Financeiro Online

Se você já está mudando de software de finanças pessoais, pode mudar para um programa online. Com o software online, você nunca precisa instalar nada no disco rígido ou esperar por atualizações.

Nota O software financeiro online geralmente é tão seguro quanto o site de banco online do seu banco e usa criptografia de dados e outros métodos para mantê-los seguros.

Aqui estão algumas alternativas de software online:

  • Você precisa de um orçamento:Também conhecido como YNAB, é um software de finanças pessoais online com fortes recursos de orçamento. Você pode usar o YNAB em computadores Windows ou Mac; com aplicativos para iPad, iPhone, Android e Kindle Fire; e por meio de um aplicativo para Apple Watch. Visualize contas, verifique seu orçamento e insira transações quando não estiver no computador.
  • Capital Pessoal:Além de mostrar todas as suas contas em um único painel, o Personal Capital também tem um foco especial em ajudá-lo a planejar seus investimentos e verificar se você está no caminho certo para a aposentadoria.

Opção 3: Microsoft Money Plus Sunset Deluxe

Se você puder fazer sem downloads automáticos de transações e alguns outros recursos que exigem acesso à Internet, o Microsoft Money Plus Sunset Deluxe ainda é uma opção. Embora não tenha todos os recursos que você gostou no Money, Sunset Deluxe é gratuito. Não existe uma versão para Mac, então esses usuários terão que escolher uma alternativa diferente.

Quicken é o melhor substituto do Microsoft Money?

Muitos que estão substituindo o Microsoft Money recorrem primeiro ao Quicken. É um software de finanças pessoais muito robusto e funciona bem. No entanto, Quicken custa entre US$ 35 e US$ 90, dependendo da versão.﻿﻿﻿﻿

Antes de mudar, considere que talvez você não consiga importar com êxito seus dados antigos do Money. Na verdade, Quicken não recomenda fortemente o processo.﻿﻿﻿﻿ Quicken também não oferece uma avaliação gratuita (embora os aplicativos móveis tenham versões gratuitas para testar). No entanto, oferece uma garantia de devolução do dinheiro, portanto, se você decidir que não funcionará para você, precisará solicitar um reembolso no prazo de 30 dias após a compra.﻿﻿﻿﻿

Aprendendo a usar o novo software de finanças pessoais

Você terá uma ligeira curva de aprendizado ao navegar em qualquer novo software de finanças pessoais que substitua o Microsoft Money. Alguns aspectos do novo software de finanças pessoais serão fáceis de usar para ex-usuários do Microsoft Money, mas seja paciente enquanto aprende como usar o software.

Nota Lembre-se de usar o menu Ajuda do novo software para aprender como usar recursos que funcionam de maneira um pouco diferente do Microsoft Money.

Perguntas frequentes (FAQ)

Qual é o melhor software de orçamento gratuito?

Existem muitas opções de software de orçamento gratuito e variam em termos de recursos, portanto, o melhor depende de suas necessidades e preferências. O Mint pode ajudá-lo a fazer um orçamento e definir metas e está disponível na web ou baixando o aplicativo Mint. O GnuCash é mais complexo e utiliza a contabilidade por partidas dobradas. Personal Capital oferece ferramentas para planejamento de aposentadoria, bem como orçamento e gastos.

O que é Intuit Mint?

Mint é um aplicativo de orçamento gratuito da Intuit, empresa por trás do TurboTax e QuickBooks. Você pode conectar todas as suas contas financeiras ao Mint e usá-lo para orçar e monitorar seu fluxo de caixa. Também lhe dá acesso à sua pontuação de crédito.
