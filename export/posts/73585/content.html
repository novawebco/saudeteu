Principais conclusões

  • É ilegal que veterinários distribuam medicamentos para animais para uso humano.
  • Os medicamentos para animais não são testados quanto à segurança como os medicamentos para humanos e podem conter impurezas.
  • Tomar antibióticos destinados a animais também pode levar à resistência aos antibióticos.

Se você trabalha em uma fazenda ou em uma clínica veterinária, pode estar se perguntando se é seguro tomar medicamentos feitos para animais. Isso pode ser tentador se você estiver doente e tiver acesso fácil a medicamentos para animais.

Há muitos problemas com isso. A primeira é que é ilegal. Os veterinários não podem dispensar medicamentos animais para uso humano. Isso inclui medicamentos como antibióticos.

Isso deve estar claro na embalagem. Os medicamentos para animais são sempre marcados como “não para consumo humano”.

Este artigo analisa os perigos de tomar medicamentos destinados a animais.

Requisitos da FDA e medicamentos para animais

Muitos medicamentos de origem animal são versões genéricas de medicamentos humanos. Por exemplo, um veterinário pode prescrever prednisona para um animal de estimação com doença inflamatória. Este é o mesmo medicamento que os humanos podem obter com receita médica.

As drogas animais, entretanto, são diferentes das drogas humanas. Por exemplo, os medicamentos fabricados para o gado destinam-se a ser misturados com a ração.

A Food and Drug Administration (FDA) testa medicamentos humanos quanto à segurança. Eles podem não realizar o mesmo nível de testes em medicamentos feitos para animais.

Os medicamentos para animais podem conter impurezas que os medicamentos para humanos não possuem. Estes podem não prejudicar os animais, mas podem ser um risco para as pessoas.

Recapitular Os medicamentos para animais não são testados em termos de segurança da mesma forma que os medicamentos para humanos. Eles também podem conter impurezas prejudiciais.

Riscos de automedicação ao tomar medicamentos para animais

O maior risco é o risco de usar o medicamento errado. Este é um problema sério se você autodiagnosticar uma infecção e depois tentar tratá-la com um antibiótico destinado a animais.

Seu diagnóstico pode não estar correto. O antibiótico também pode não ser o adequado para tratar a infecção.

Algumas pessoas podem optar por tomar antibióticos para animais devido a preocupações com custos. Com a maioria dos antibióticos, porém, o custo direto é baixo. Muitos antibióticos são genéricos. Alguns podem ser adquiridos por apenas US$ 4 mediante receita médica.

O diagnóstico ou medicação errada pode colocar a sua saúde em grande risco.

Resistência a antibióticos e medicamentos para animais

As “superbactérias” são um dos maiores problemas de saúde do mundo. Estas são bactérias que se tornam resistentes a vários antibióticos.

Sem antibióticos eficazes, essas bactérias não podem ser controladas. Podem ocorrer infecções terríveis e mortais.

Alguém que toma antibióticos para animais sem supervisão médica aumenta o risco de contrair uma superbactéria.

Isso é perigoso para o indivíduo porque essas bactérias permanecem no corpo. Eles podem causar uma infecção posterior que é muito difícil de tratar.

Para o público, novas superbactérias podem agravar o problema da resistência aos antibióticos. Este é um problema que assola a saúde moderna.
