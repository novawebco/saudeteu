Principais conclusões

  • Um ingrediente farmacêutico ativo é a parte de um medicamento que o faz funcionar.
  • Os APIs dos medicamentos podem ser os mesmos tanto nos formatos de venda livre quanto nos de prescrição, como o paracetamol no Tylenol.
  • Converse com seu farmacêutico ou verifique o rótulo para saber o API de qualquer medicamento que você esteja tomando.

Um ingrediente farmacêutico ativo (API) é o componente de um medicamento de venda livre (OTC) ou de prescrição que produz os efeitos pretendidos à saúde. Se um medicamento prescrito tiver um genérico, seu nome será igual ao seu API. As terapias combinadas têm mais de um ingrediente ativo, cada um dos quais pode agir de maneira diferente ou tratar sintomas diferentes.

É uma boa ideia conhecer os APIs dos medicamentos que você toma. (Por exemplo, paracetamol – o ingrediente ativo do Tylenol – é um API bem conhecido.) Isso pode ajudá-lo a se comunicar melhor com seus profissionais de saúde, reconhecer quais genéricos e versões de marca são iguais e evitar interações prejudiciais e overdoses acidentais.

Este artigo discute APIs, o que são, por que são importantes e como encontrá-los no rótulo de um medicamento.

APIs e outros componentes de medicamentos

Os medicamentos são fabricados sob condições rigorosas para manter a consistência e minimizar o risco de contaminação.

Todos os medicamentos são compostos por dois componentes principais:

  • OAPIé o ingrediente central. Os APIs são produzidos a partir de matérias-primas com resistência e concentração química especificadas.
  • Oexcipienteinclui outras substâncias além do medicamento que ajudam a administrar o medicamento ao seu sistema.

Excipientes são substâncias quimicamente inativas, como aglutinantes, conservantes e corantes artificiais que dão cor ao comprimido. Alguns desses materiais são usados ​​para ajudar o medicamento a permanecer estável e para controlar a absorção quando você o toma. Excipientes como glúten, lactose, açúcar e alguns corantes podem causar reações alérgicas em algumas pessoas.

A Food and Drug Administration (FDA) exige testes de equivalência para medicamentos genéricos para garantir que tenham a mesma potência das versões de marca.Alguns medicamentos genéricos podem conter excipientes diferentes das versões de marca, mas muitos genéricos são idênticos a eles.

Por que você deve procurar APIs

Há muitas situações em que você se beneficiará ao conhecer os APIs dos medicamentos que está tomando.

Aqui estão alguns exemplos:

  • Um medicamento prescrito usado para tratar a artrite é a combinação de ibuprofeno (um antiinflamatório) e famotidina (que protege contra úlceras). O ibuprofeno também está disponível na forma OTC como Advil, Motrin e como genérico. A famotidina está disponível na forma OTC como Pepcid.
  • Robitussin DM é um medicamento de venda livre comumente usado para tratar sintomas de um resfriado comum. Este medicamento contém dextrometorfano, um supressor de tosse, e guaifenesina, um expectorante. A guaifenesina também é o API do Mucinex e o dextrometorfano é o API do Delsym.

Você pode acabar tomando muito desses APIs se não souber que eles estão disponíveis em diferentes medicamentos e marcas. Além disso, se um medicamento que você está tomando não estiver funcionando ou causando efeitos colaterais, você poderá evitar pular para a mesma API com um nome diferente em uma tentativa potencialmente fútil de tentar algo que você acha que é diferente.

Como encontrar uma API no rótulo de um medicamento

Para medicamentos OTC, o API e a quantidade que cada dose contém estão listados na parte superior do rótulo de informações sobre medicamentos, sob o título "Ingrediente ativo". O efeito na saúde está listado à direita dessa informação.

Os rótulos dos medicamentos prescritos listam o nome da marca do medicamento (se aplicável) acima do nome genérico. O nome genérico também é o API desse medicamento. Se você recebeu a versão genérica do medicamento, o rótulo também poderá informar sob qual marca o medicamento geralmente é vendido. Por exemplo: "Anfetamina 10MG: Genérico para Adderall 10MG."

O nome genérico de um medicamento é normalmente um derivado do nome químico, que é usado com menos frequência. Por exemplo, o nome químico da aspirina é ácido acetilsalicílico.

Onde as APIs são feitas?

Além dos EUA, os maiores fabricantes de APIs estão localizados na Ásia, especialmente na Índia e na China, de acordo com a FDA.Normalmente, a empresa farmacêutica que produz um medicamento utiliza as medidas de segurança do seu próprio país ao produzir o produto final.

Se você quiser ter certeza de que seu medicamento foi aprovado em seu país de origem, é importante que você obtenha seus medicamentos em um revendedor confiável.
