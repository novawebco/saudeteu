Principais conclusões

  • Um documento de requisitos de negócios estabelece os requisitos de um projeto para que todos os envolvidos saibam o que deve ser feito e quando. 
  • Também pode incluir elementos que constituem um contrato, como condições de pagamento pelo trabalho. 
  • Um documento de requisitos comerciais é diferente de um plano de negócios ou de uma solicitação de proposta.

Como funciona um documento de requisitos de negócios

Sua pequena empresa está se preparando para expandir ou vender novos produtos ou uma variedade de mudanças, e você pode estar procurando um consultor ou empreiteiro para ajudá-lo nesse projeto. Uma das primeiras coisas que você precisará fazer é preparar um documento de requisitos de negócios para descrever o projeto e o que precisa ser feito para que ele aconteça.

O principal objetivo de um documento de requisitos de negócio é esclarecer tudo o que precisa ser abordado para que o projeto seja bem-sucedido, com requisitos detalhados para cada parte do projeto.

Observação

Um documento de requisitos de negócios pode ser usado por uma empresa, agência governamental, instituição educacional, organização sem fins lucrativos ou outro tipo de organização. 

Um documento de requisitos de negócios (BRD) pode ser considerado em duas fases. Na primeira fase de um projeto, é um documento que estabelece todos os requisitos do projeto, incluindo custos, detalhes de implementação, benefícios projetados, marcos e cronograma de implementação. 

Na segunda fase, o documento pode se tornar um contrato entre as duas partes, estabelecendo formalmente os requisitos de uma empresa contratante (ZXY, Inc. neste caso) e do empreiteiro que executa o trabalho.  

Nomes alternativos para um BRD incluem Documento de Requisitos do Projeto e Documento de Especificação de Requisitos.

Exemplo de documento de requisitos de negócios

Uma empresa (vamos chamá-la de ZXY Inc.) decidiu terceirizar suas funções de contabilidade para um centro de serviços compartilhados nos EUA. Eles estão iniciando um processo de localização, configuração dos serviços, contratação e gerenciamento de funcionários. É uma tarefa complicada e levará muitos meses para ser realizada. Eles começam com uma equipe que prepara um documento de requisitos de negócios.

Como um documento de requisitos de negócios difere de um plano de negócios

Embora tanto um BRD como um plano de negócios possam conter secções semelhantes (um resumo executivo, por exemplo), a intenção é diferente.

Um plano de negócios é criado para orientar um negócio novo ou existente, mas mais frequentemente seu objetivo é apresentá-lo a um credor para financiar o início ou expansão.

O plano de negócios contém informações gerais sobre a empresa e seus planos e estratégias para conseguir gerar receitas para pagar o empréstimo. As demonstrações financeiras são uma parte fundamental do plano de negócios, enquanto os documentos financeiros no BRD podem ser bastante diferentes, centrados num projeto específico. 

Como um documento de requisitos de negócios é diferente de uma solicitação de proposta (RFP)

A diferença entre os dois documentos é pequena, mas importante. Normalmente, uma solicitação de proposta (RFP) é criada com a finalidade de convidar propostas de vários fornecedores. No exemplo da ZXY, Inc,, uma RFP é enviada a potenciais empresas que fornecem serviços de terceirização, para solicitar licitações. 

Um BRD, por outro lado, é preparado para um fornecedor específico ou parceiro de joint venture que já foi selecionado pela empresa contratante. O BRD contém mais detalhes e mais especificações e prazos a serem cumpridos ao longo do caminho e ao final do projeto. 

Quando uma RFP é criada, ela vem com um prazo e requisitos para envio de propostas. As propostas são avaliadas após o prazo.

O que deve ser incluído em um documento de requisitos comerciais

De certa forma, um documento de requisitos de negócios é semelhante a outros tipos de propostas de negócios, mas a diferença está na parte principal do documento, a listagem de requisitos básicos.

Observação

Seja o mais detalhado possível ao escrever este documento. É uma boa ideia contratar um advogado para ajudá-lo a garantir que você não perca nada importante.

 O BRD deve incluir estas seções:

  • Introdução: Comece com uma declaração que forneça uma descrição ampla do projeto e uma declaração de antecedentes descrevendo por que o projeto é necessário. Inclua informações sobre as partes do projeto. 
  • Definição: defina e descreva todos os termos importantes para que todos falem sobre a mesma coisa. 
  • Uma declaração de propósito: Declare claramente o objetivo do projeto e comece com as palavras: “O objetivo deste documento é…” 
  • Requisitos básicos: Esta é a parte principal do documento. Liste todos os requisitos do projeto, sendo o mais detalhado possível. No exemplo da ZXY, Inc., uma seção pode ser os requisitos para a contratação de funcionários de contabilidade. Quantos são necessários? Que habilidades eles possuem? Quais credenciais? Quais leis trabalhistas a empresa contratante deve seguir? 
  • Prazos e pontos de verificação provisórios: Cronogramas, Fluxogramas e Diagramas. Inclua quaisquer recursos visuais que você acha que irão melhorar a compreensão e esclarecer o processo. Certifique-se de incluir um cronograma detalhado. 
  • Assinaturas: Finalmente, inclua um local para assinaturas de ambas as partes atestando o fato de que os indivíduos leram e compreenderam os termos do documento e que concordam em cumpri-los.

O que torna um documento de requisitos de negócios um contrato

Na fase inicial, o documento de requisitos de negócios é uma proposta. Você deve ter notado que faltava algo na lista de seções acima: pagamento por serviços prestados. Sem um acordo sobre os serviços a serem prestados e as condições de pagamento, não há contrato.

Antes de as duas partes assinarem o documento, o texto padrão do contrato deve ser adicionado, com a ajuda de um advogado, incluindo:

  • Promessas de pagamento e promessas de prestação de serviços
  • Convênios Restritivos, impedindo que o contratante tome segredos comerciais da empresa ou os compartilhe com terceiros.
  • O que acontece se uma das partes não cumprir as obrigações exigidas (ou seja, violar o contrato)
  • Cláusulas de seguro e indenização (isenção de responsabilidade)
  • Disposições de litígio e arbitragem

Perguntas frequentes (FAQ)

Como redigir um documento de requisitos de negócios?

Comece com a declaração de propósito para garantir que tudo no documento esteja focado no propósito. Em seguida, escreva definições para garantir que todos estejam falando sobre as mesmas coisas. A maior parte deste documento é a lista de todos os requisitos do projeto. Inclua gráficos, uma linha do tempo e outros recursos visuais de apoio.

Qual é um exemplo de requisito de negócios?

Se uma empresa está solicitando software para operar seu armazém, um requisito pode ser que o software seja capaz de incluir quantos produtos e quais tipos precisam estar em estoque. Outro requisito pode ser o rastreamento da localização e do status (pronto para envio, data de envio, etc.). Ainda outro requisito pode ser que o software de armazenamento se conecte ao software de contabilidade da empresa.
