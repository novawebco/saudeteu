  • O livro de quebra-cabeças da linguagem de sinais americana: Os quebra-cabeças deste livro são organizados por temas como saúde. As ilustrações são de uma conhecida artista surda, Betty Miller.
  • O livro de quebra-cabeças da linguagem de sinais americana, volume dois: Esta sequência tem mais 120 quebra-cabeças, novamente com ilustrações de Betty Miller.
  • O livro de quebra-cabeças com formato de mão da linguagem de sinais americana: Este livro contém 54 palavras cruzadas e caça-palavras que usam formatos de mão.
  • Aprenda a sinalizar de maneira divertida: deixe seus dedos falarem com jogos, quebra-cabeças e atividades em linguagem de sinais americana: Este é um livro voltado para crianças com jogos focados em signos organizados em grupos com temas como Animais.
  • A alegria de assinar um livro de quebra-cabeças: Os quebra-cabeças deste livro são baseados no livroA alegria de assinar.

Jogos de linguagem de sinais para amigos

O jogo de palavras cruzadas Keep Quiet, uma forma de linguagem de sinais do Boggle, está disponível através de fornecedores de produtos para pessoas surdas e com deficiência auditiva. Outros jogos de linguagem de sinais, que podem estar disponíveis através de fornecedores de produtos para surdos e deficientes auditivos, são:

  • Sign It!: um jogo de tabuleiro que desafia você a assinar palavras em cartas.
  • Veja e assine: um jogo multinível que ensina sinais em categorias de seis palavras e vem com um DVD Compare Preços.
  • ASLingo: um jogo de bingo em linguagem de sinais.
  • Finger Alphabet Lotto: um jogo de correspondência para aprender o alfabeto da linguagem de sinais.
  • Cartas de jogar em linguagem de sinais.
  • Flashcards para aprender linguagem de sinais.
  • O Mistério da Casa do Superintendente é um jogo semelhante ao Clue.

Jogos Online de Linguagem de Sinais

Os jogos de linguagem de sinais online incluem:

  • O site ABCTeach possui vários itens para impressão relacionados à linguagem de sinais. O registro é necessário para alguns itens.
  • SurfnetKids.com tem um jogo de concentração Fingerspelling
  • Funbrain.com tem um jogo de identificação de alfabeto/número.
  • Enchanted Learning possui flashcards e etiquetas impressas.
