Um número de conta bancária internacional (IBAN) identifica uma conta bancária específica em um formato que facilita as transferências internacionais de dinheiro. Os IBANs têm até 34 caracteres alfanuméricos e seguem um padrão aceito internacionalmente que os torna úteis em vários países ao redor do mundo.

Definição e exemplos de IBAN

Um IBAN é um identificador exclusivo que bancos de todo o mundo podem usar para fazer referência a uma conta bancária específica. O sistema IBAN inclui informações sobre a conta bancária, o banco titular da conta e o país onde a conta está localizada. Os bancos usam as informações para enviar dinheiro rapidamente (ou receber fundos de) uma conta em um país diferente.

Observação

As BANs são definidas pela Organização Internacional de Padronização (ISO) sob a ISO 13616.

Se quiser enviar dinheiro para uma conta bancária noutro país, muitas vezes terá de fornecer um IBAN, que pode solicitar ao destinatário. Em alguns casos, os bancos não utilizam IBANs, mas esses bancos podem fornecer instruções alternativas sobre como transferir fundos para a sua conta. Por exemplo, os bancos dos EUA podem não usar o padrão IBAN, então normalmente você não precisa de um IBAN ao transferir fundos para um banco com sede nos EUA.

Um IBAN pode ter a seguinte aparência: DE17ABCD12345698765. A sequência alfanumérica e o agrupamento têm um significado específico. 

Como funciona um IBAN?

Os bancos em vários países ao redor do mundo seguem o mesmo conjunto de regras para criar e utilizar IBANs, o que torna possível a transferência de fundos com relativa facilidade. Cada IBAN pode conter até 34 caracteres e os componentes têm uma finalidade específica. Na maioria dos casos, os caracteres seguem a sequência abaixo.

Código do país

Os primeiros dois dígitos são o código do país, que especifica a localização da conta bancária. Por exemplo, o código do país para a Alemanha é “DE”.

Verifique os dígitos

Os próximos dois dígitos são dígitos de verificação, que permitem aos bancos verificar se o IBAN é válido antes de processar uma transferência. Usando um cálculo matemático, os bancos podem determinar se há algum erro na entrada de dados antes de enviar dinheiro. Reverter pagamentos no exterior pode ser complicado, por isso é melhor evitar problemas em primeiro lugar.

Identificador do Banco

O identificador do banco especifica qual banco mantém a conta. Este código – ou um código adicional, dependendo do país – também pode identificar uma agência bancária específica para a conta.

Número Básico de Conta Bancária (BBAN) 

O BBAN define a conta individual à qual a transferência se aplica. Esse número é equivalente ao que você pode conhecer como “número da conta”. Novamente, uma vez que um IBAN se refere a uma conta específica – como a sua conta individual ou conjunta – esta informação é necessária.

Observação

Cada país tem margem de manobra para definir o comprimento de um IBAN. Por exemplo, um IBAN para a Noruega usa 15 caracteres, enquanto a Islândia usa 26 caracteres.

Alternativas aos IBANs

Você pode precisar de números de referência adicionais para algumas transferências internacionais de dinheiro. Por exemplo, você pode usar um código de identificação bancária (BIC) ou um código da Sociedade para Telecomunicações Financeiras Interbancárias Mundiais (SWIFT) para facilitar os pagamentos. BIC e SWIFT às vezes são usados ​​de forma intercambiável, e BIC também pode se referir a um “código identificador de banco”.

Os códigos SWIFT especificam bancos e instituições financeiras em todo o mundo; eles são como um número de roteamento. No entanto, ao contrário dos IBANs, os códigos SWIFT não se referem a uma conta específica num determinado banco – é necessário fornecer detalhes adicionais além de um código SWIFT para creditar fundos numa conta específica. E, em alguns casos, é melhor fornecer um código IBAN e um código SWIFT para garantir que sua transferência ocorra sem problemas.

Os bancos também podem solicitar números de roteamento, também conhecidos como números “ABA” quando você faz uma transferência internacional. Mas provavelmente esse é o caso apenas quando você transfere fundos para um banco dos EUA. Os bancos de outros países tendem a usar códigos SWIFT e IBANs. Os EUA não utilizam atualmente o padrão IBAN, portanto os bancos nos EUA podem não permitir o uso de IBANs.

Principais conclusões

  • Os IBANs são necessários para algumas transferências internacionais entre bancos.
  • Um IBAN identifica uma conta específica em uma instituição financeira.
  • Os IBANs utilizam um formato padronizado e aceito em vários países.
  • Pode ser necessário fornecer dados bancários e de conta adicionais para concluir uma transferência de dinheiro para o exterior.
